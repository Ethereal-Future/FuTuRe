# compliance/complianceReporting.js: SAR/CTR report generation lacks automated schema validation against FinCEN electronic filing specifications

**Domain:** Compliance & AML  
**Complexity:** Medium  
**Labels:** `enhancement`, `compliance`, `reporting`  
**Issue ID:** ISSUE-086

---

## Background
In `backend/src/compliance/complianceReporting.js`, `generateSAR()` and `generateCTR()` generate regulatory Suspicious Activity Reports (SAR) and Currency Transaction Reports (CTR) for FinCEN reporting. The reports are formatted as custom JSON objects.

## Problem
- FinCEN requires electronic filings to strictly adhere to the BSA E-Filing XML Batch Schema specifications (FinCEN Form 111 / XML User Guide).
- The JSON output generated by `complianceReporting.js` uses arbitrary internal field names (e.g. `senderId`, `alertDescription`, `txHash`) that do not match FinCEN's standard XML schema elements.
- Compliance teams must manually re-enter data into FinCEN's portal because reports cannot be directly exported or submitted, delaying mandatory 30-day SAR filing deadlines.

## Proposed Solution
Implement FinCEN XML schema formatting in `complianceReporting.js`:
1. Generate valid FinCEN BSA XML compliant with the official FinCEN XML schema version 2.0.
2. Include mandatory filing elements: Transmitter, Filing Institution, Activity (Suspicious Activity Information / Currency Transaction), Subject (Individual/Entity), and Narrative.
3. Validate generated XML against the official FinCEN XSD schema using `libxmljs` or `fast-xml-parser` before saving.

## Implementation Steps
1. Create FinCEN XML generator template in `backend/src/compliance/fincenXml.js`.
2. Map internal user, transaction, and KYC models to FinCEN schema fields.
3. Add XSD schema validation verifying structure, required attributes, and date formats.
4. Expose endpoint `GET /api/compliance/reports/:reportId/export-xml` for direct compliance submission.
5. Add unit tests validating sample SAR output against FinCEN schema.

## Acceptance Criteria
- [ ] SAR and CTR reports can be exported directly in valid FinCEN BSA XML format.
- [ ] Generated XML passes official XSD schema validation.
- [ ] Manual data re-entry for compliance officers is eliminated.
