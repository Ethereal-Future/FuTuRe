# recovery/recoveryPhrase.js: Mnemonic recovery phrase generation does not use PBKDF2 with 2048 iterations as required by BIP-39 specification

**Domain:** Account Recovery & Custody  
**Complexity:** Hard  
**Labels:** `bug`, `cryptography`, `security`, `stellar`  
**Issue ID:** ISSUE-143

---

## Background
In `backend/src/recovery/recoveryPhrase.js`, seed generation converts mnemonic words to cryptographic seeds:
```javascript
export function mnemonicToSeed(mnemonic, passphrase = '') {
  return crypto.createHash('sha256').update(mnemonic + passphrase).digest();
}
```

## Problem
- The BIP-39 standard (used by Stellar wallets like Freighter, Albedo, and Lobstr) strictly mandates that mnemonic phrases MUST be converted to binary seeds using **PBKDF2 with HMAC-SHA512**, with salt `"mnemonic" + passphrase`, and **2,048 iterations**.
- Using a single unsalted SHA-256 hash completely breaks compatibility with all external Stellar wallets!
- A seed phrase generated by this platform cannot be restored in Freighter or Ledger.
- Furthermore, a single SHA-256 hash is susceptible to high-speed GPU dictionary attacks, weakening the security of user recovery phrases by multiple orders of magnitude.

## Proposed Solution
Implement full BIP-39 specification compliance using `@scure/bip39` or Node's `crypto.pbkdf2Sync`:
```javascript
import { pbkdf2Sync } from 'crypto';

export function mnemonicToSeed(mnemonic, passphrase = '') {
  const normalizedMnemonic = mnemonic.normalize('NFKD');
  const salt = ('mnemonic' + passphrase).normalize('NFKD');
  return pbkdf2Sync(normalizedMnemonic, salt, 2048, 64, 'sha512');
}
```
Derive Stellar ed25519 keypairs from the 64-byte seed using standard SLIP-0010 derivation (`m/44'/148'/0'`).

## Implementation Steps
1. Refactor `mnemonicToSeed` in `backend/src/recovery/recoveryPhrase.js` to use PBKDF2 HMAC-SHA512 with 2048 iterations and NFKD normalization.
2. Implement SLIP-0010 ed25519 derivation path for Stellar.
3. Add test vectors from the official BIP-39 specification verifying identical seed outputs.
4. Verify exported phrases can be restored in standard Stellar ecosystem wallets.

## Acceptance Criteria
- [ ] Mnemonic generation and seed derivation adhere strictly to BIP-39 and SLIP-0010.
- [ ] Passphrase salting and 2048 iterations are enforced.
- [ ] Keys generated from recovery phrases are 100% interoperable with Freighter and standard Stellar wallets.
